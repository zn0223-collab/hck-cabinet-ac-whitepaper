**HCK** (Zhejiang Haocheng Industrial Control Equipment Co., Ltd.) designs and manufactures
closed-loop **cabinet / box-type / prefabricated-cabin air conditioners** from 2000 to 7500 W,
built for IP55, −40…+55 °C, R410A, rotary compressor, RS485/Modbus, CE-marked, OEM/ODM.

## Technical white paper
- PDF (in this repo): [whitepaper.pdf](whitepaper.pdf)

The paper covers closed-loop cooling原理, a **reproducible cooling-load method**
`Q = Q_internal + U·A·ΔT` (with worked example), the full product range, a step-by-step
selection guide, and applications in energy-storage cabins, prefabricated substations, telecom
base stations, EV-charging cabinets, mining and offshore platforms.
